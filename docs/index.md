# hpc-job-profiler

`hjp` sizes Slurm jobs for bioinformatics tools from measurements and reviews
them afterwards: `hjp calibrate` before submission, `hjp watch` during the
run, `hjp report` after it. Start with the [user guide](user_guide.md), or
[why profiling saves cluster time](why_profiling.md) for a non-technical
introduction. The repository README has a quick start.
