# pipeprof

`pipeprof` sizes Slurm jobs for bioinformatics tools from measurements and reviews
them afterwards: `pipeprof calibrate` before submission, `pipeprof watch` during the
run, `pipeprof report` after it. Start with the [user guide](user_guide.md), or
[why profiling saves cluster time](why_profiling.md) for a non-technical
introduction. The repository README has a quick start;
[clusters.md](clusters.md) covers installing and running on Alliance clusters.
